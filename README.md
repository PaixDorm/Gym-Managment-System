# Gym Management System
### سامانه مدیریت باشگاه ورزشی

**پروژه نهایی مینی‌کمپ پایتون آلفا — دوره QBC13 کوئرا**

## معرفی پروژه

سامانه مدیریت باشگاه ورزشی یک برنامه ترمینالی است که با زبان **Python** و با هدف مدیریت فعالیت‌های یک باشگاه طراحی شده است.

این پروژه دارای سه نوع کاربر اصلی است:

- **Manager:** مدیر باشگاه
- **Coach:** مربی
- **Member:** عضو باشگاه

هدف پروژه، پیاده‌سازی یک سیستم کاربردی با استفاده از مفاهیم برنامه‌نویسی شیءگرا، مدیریت فایل، اعتبارسنجی، مدیریت خطا، دکوراتورها، ژنراتورها و کار تیمی با Git و GitHub است.

---

## امکانات سیستم

### ۱. مدیریت ورود کاربران (Authentication)

- ورود مدیر، مربی و عضو با نام کاربری و رمز عبور
- بررسی نقش کاربر هنگام ورود
- جلوگیری از ورود کاربران غیرفعال
- امکان تلاش مجدد پس از ورود ناموفق
- امکان بازگشت به منوی اصلی
- ثبت نتیجه تلاش‌های ورود در فایل لاگ

### ۲. پنل مدیر (Manager Panel)

بخش مدیریت کاربران شامل امکانات زیر است:

- افزودن مربی و عضو جدید
- مشاهده اطلاعات کاربران
- ویرایش نام، ایمیل و رمز عبور
- فعال و غیرفعال کردن حساب کاربران
- جلوگیری از غیرفعال کردن حساب مدیر توسط خودش
- بازگشت به منوی اصلی

بخش مدیریت سالن‌ها شامل موارد زیر است:

- افزودن سالن ورزشی
- تعیین ظرفیت و تجهیزات سالن
- مشاهده سالن‌های ثبت‌شده
- فعال و غیرفعال کردن سالن‌ها

مدیریت کلاس‌های گروهی، پرداخت‌ها و گزارش‌های مدیریتی نیز در ساختار پروژه پیش‌بینی شده‌اند و اتصال نهایی آن‌ها در حال انجام است.

### ۳. پنل مربی (Coach Panel)

قابلیت‌های در نظر گرفته‌شده:

- مشاهده کلاس‌های مربوط به مربی
- مشاهده اعضای ثبت‌نام‌شده
- ایجاد و ویرایش برنامه تمرینی اعضا
- ثبت حرکات تمرینی، تعداد ست، تکرار و زمان استراحت
- محدودسازی دسترسی مربی به کلاس‌ها و اعضای خودش

تکمیل و یکپارچه‌سازی این بخش با سایر ماژول‌ها در حال انجام است.

### ۴. پنل عضو (Member Panel)

قابلیت‌های در نظر گرفته‌شده:

- مشاهده پروفایل و وضعیت اشتراک
- مشاهده موجودی کیف پول
- شارژ کیف پول
- مشاهده سابقه تراکنش‌ها
- خرید یا تمدید اشتراک
- مشاهده کلاس‌های قابل ثبت‌نام
- ثبت‌نام و انصراف از کلاس
- مشاهده برنامه تمرینی

بعضی از این امکانات پیاده‌سازی اولیه شده‌اند و اتصال و تست نهایی آن‌ها هنوز ادامه دارد.

### ۵. مدیریت فایل‌ها (File Management)

اطلاعات پروژه با استفاده از فایل‌های متنی ذخیره و بازیابی می‌شوند.

عملیات اصلی مدیریت فایل شامل:

- خواندن اطلاعات
- نوشتن اطلاعات
- اضافه کردن اطلاعات جدید
- به‌روزرسانی اطلاعات موجود
- مدیریت خطاهای رایج فایل

### ۶. ثبت فعالیت‌ها (Activity Logging)

سیستم با استفاده از Decorator فعالیت‌های مهم را ثبت می‌کند.

هر لاگ شامل اطلاعات زیر است:

- زمان انجام فعالیت
- نام عملیات
- نقش کاربر
- نام کاربری
- نتیجه موفق یا ناموفق بودن عملیات

نتیجه تلاش‌های ورود در فایل `data/activity_logs.txt` ذخیره می‌شود.

## پیش‌نیازهای اجرا

- Python 3.12
- Git برای مدیریت نسخه‌ها
- یک ترمینال یا محیط برنامه‌نویسی مانند PyCharm

بخش‌های اصلی پروژه از کتابخانه‌های استاندارد پایتون مانند `datetime`، `functools`، `inspect`، `re` و `unittest` استفاده می‌کنند.

برای اجرای تست‌های مبتنی بر `pytest`، نصب این ابزار نیز ممکن است لازم باشد.

همچنین برای عملکرد بخش بانکی، فایل `Bank.py` ارائه‌شده همراه صورت پروژه باید در مسیر مورد انتظار کد موجود باشد.

## نحوه اجرای پروژه

ابتدا ترمینال را در پوشه اصلی پروژه باز کنید.

سپس دستور زیر را اجرا کنید:

```bash
python main.py
```

منوی شروع برنامه نمایش داده می‌شود:

```text
1. ورود مدیر باشگاه
2. ورود مربی
3. ورود عضو باشگاه
4. خروج
```

پس از انتخاب نقش، کاربر باید نام کاربری و رمز عبور خود را وارد کند.

در صورت موفقیت ورود، سیستم کاربر را به بخش مرتبط با نقش او هدایت می‌کند؛ البته نمایش بعضی پنل‌ها تا تکمیل یکپارچه‌سازی نهایی در حال توسعه است.

### حساب‌های کاربری اولیه

برای ورود موفق، باید اطلاعات یک کاربر معتبر در فایل کاربران وجود داشته باشد.

حساب مدیر اولیه در محیط توسعه به‌صورت جداگانه ایجاد شده است.

**نام کاربری و رمز عبور واقعی یا آزمایشی کاربران نباید داخل README نوشته شوند.**

برای افزایش پایداری سیستم، در بخش‌های مختلف از اعتبارسنجی اطلاعات و مدیریت استثناها استفاده شده است.

نمونه موارد بررسی‌شده:

- جلوگیری از انتخاب گزینه نامعتبر در منوها

- اعتبارسنجی نام کاربری، ایمیل و رمز عبور

- مدیریت خطاهای خواندن و نوشتن فایل
- ثبت فعالیت‌های موفق و ناموفق

توابع کمکی مشترک در فایل `src/utils/helpers.py` قرار دارند.

## تست پروژه

برای تست بخش ورود کاربران، از کتابخانه `unittest` استفاده شده است.

دستور اجرای تست‌های Authentication:

```bash
python -m unittest tests/test_auth.py
```

### نتیجه آخرین تست Authentication

**۳ تست از ۳ تست با موفقیت اجرا شده‌اند.**

سناریوهای بررسی‌شده:

- ورود موفق با اطلاعات صحیح
- جلوگیری از ورود با رمز عبور اشتباه
- جلوگیری از ورود کاربر غیرفعال

تست‌های مربوط به سالن‌ها، کلاس‌ها، کیف پول، اشتراک و برنامه‌های تمرینی توسط اعضای تیم در برنچ‌های مربوطه توسعه داده شده‌اند.

تست کامل یکپارچه‌سازی سیستم هنوز در حال انجام است.
